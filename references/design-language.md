# 视觉语言规格

这一页是「照着做就不会做错」的清单。所有数值都写在 `scripts/kit.py` 的
`NEUTRAL_THEME` 里，换主题时两边一起改。

---

## 1. 页面与栅格

单位一律**英寸**。

| 常量 | 值 | 含义 |
|---|---|---|
| `W` × `H` | 13.33 × 7.5 | 16:9 宽屏 |
| `M` | 0.66 | 左右边距 |
| `CW` | 12.01 | 内容区宽（右边界 `R = M + CW = 12.67`） |
| 标题带 | y 0.41–1.24 | **版式自带的装饰**，页面代码只写字，不画带 |
| `CT_TOP` | 1.66 | 内容区顶：标题带 + 章节标签之下 |
| `CT_BOT` | 6.94 | 内容区底 |
| `FTY` | 6.96 | 页脚文字基线 |
| `FOOT_TOP` | 6.98 | 页脚带起点，正文不许越进来 |

等分栅格在页面代码里算出来，不手写：

```python
BW3, GAP3 = 3.90, 0.155          # 3 × 3.90 + 2 × 0.155 = 12.01 = CW
X3 = [M + i * (BW3 + GAP3) for i in range(3)]
BW4, GAP4 = 2.875, 0.17          # 4 × 2.875 + 3 × 0.17 = 12.01
X4 = [M + i * (BW4 + GAP4) for i in range(4)]
```

块间距统一在 `0.15–0.22in`。低于 0.15 显得挤，高于 0.30 会被闸门四当成空隙
（`VOID_TOL = 0.30in`，只记录不判缺陷；到 `VOID_BAD = 0.55in` 才判缺陷）。

**纵向排布按实测墨迹算，不按声明的框高算。** 声明框高 1.14in 的描述块，
实际墨迹可能只有 0.72in；按框高留缝会在页面上段留出一条大空隙。
所以先估文字占几行（几行 × 字号 × 行距），再定下一个块的 y。

## 2. 色板

比值是 **WCAG 2.1 对比度**，对白底（标注了「在某色块上」的除外）。
判定门槛：大字（≥18pt，或 ≥14pt 粗体）≥ 3.0；小字 ≥ 4.5。

| 常量 | 值 | 承白字 | 承 `BAND` | 适用 | **禁用** |
|---|---|---|---|---|---|
| `BAND` | `006DB8` | 5.41:1 | — | 标题带、结论带、深色面板、强调数字 | — |
| `BORDER` | `4472C4` | 4.72:1 | — | 内容框描边 2.25pt、淡底上的强调字 | 淡底上的**小字**（在 `TINT` 上只有 4.32:1，不过线） |
| `ACC` | `6096E6` | 3.00:1 | 1.80:1 | **只做装饰线、分隔线** | 任何文字；蓝底上的高亮 |
| `SKY` | `E8F2FB` | — | 4.77:1 | **只在 `BAND` 上**做浅色字 | 白底（太浅）；`BORDER` 上（4.24:1） |
| `TABBG` | `D3D9E9` | — | — | 编号标签底，承深字 12.99:1 | — |
| `NUM` | `7B8DBE` | 3.28:1 | — | 编号圆（20pt 粗体白字） | 更大字号的正文 |
| `TINT` | `F2F6FB` | — | — | 淡底卡片，承 `BAND` 字 4.99:1 | 小字一律换 `BAND`（`BORDER` 在这上面不过线） |
| `BROWN` | `B39B77` | 2.67:1 | — | **纯装饰**：色带、色线、小方块 | **任何文字** |
| `INK` | `0F1423` | 18.35:1 | — | 标题、正文强调 | — |
| `BODY` | `262626` | 15.13:1 | — | 正文 | — |
| `MUTED` | `56646E` | 6.10:1 | — | 弱化文字、图注、页脚 | — |
| `WHITE` | `FFFFFF` | — | — | 深色块上的文字 | — |

> 本节的每一个比值都由 `make_neutral_template.py` 的 `report_contrast()` 按
> WCAG 2.1 公式**实算并打印**（`python scripts\make_neutral_template.py --theme <名>`），
> 不是估的。改色之后先看那张表，低于 4.5 / 3.0 的组合直接不要用。

### 两条最常踩的坑

1. **`BORDER` 在 `TINT` 上只有 4.32:1**，小字不过 4.5 的线。
   所以淡底卡片上的字一律用 `BAND`（对 `TINT` 4.99:1）。
2. **`ACC` 在 `BAND` 上只有 1.80:1**。蓝底上的高亮必须用 `SKY` 或 `WHITE`，
   想用 `ACC` 就只能拿它画线。

闸门三会逐个片段算这两条，但它报的时候你已经写完了；写的时候就按上表挑，能省一轮返工。

## 2b. 三套主题

三套主题的**栅格与字体完全相同**，只换色板与母版装饰色。原因是这两样和「什么场合」
无关：换色板是最容易改也最该改的一层，把栅格一起换等于把整份稿重排一遍。

| | `academic-blue` | `scholar-red` | `minimal-mono` |
|---|---|---|---|
| 基色 | 商务蓝 `006DB8` | 学术暗红 `8A2B34` | 近黑灰 `2F2F2F` |
| 强调色 | `ACC 6096E6`（浅蓝，装饰用） | `ACC C06C74`（浅红，装饰用） | `ACC B5532C`（陶土橙，**唯一强调色**） |
| 定位 | 默认，通用 | 正式、评审场合 | 打印稿、外部评审 |
| 适合 | 组会、学术会议、对外介绍 | 开题/中期、答辩、项目评审 | 黑白打印、投稿附件、不希望颜色先入为主 |
| 投影建议 | 亮环境；偏暗投影时改 `scholar-red` | 亮环境；红底在偏色投影上会偏紫 | 亮暗环境都可，灰阶不挑设备 |
| 母版 | `assets/themes/academic-blue.pptx`（另存别名 `assets/theme-neutral.pptx`） | `assets/themes/scholar-red.pptx` | `assets/themes/minimal-mono.pptx` |
| 正文 | `微软雅黑` + `Times New Roman` | 同左 | 同左 |
| 栅格 | M 0.66 / CW 12.01 / CT_TOP 1.66 | 同左 | 同左 |

### 实测对比度（三套都过闸门三）

`make_neutral_template.py` 打印的原始输出，按角色对齐：

| 组合（门槛） | `academic-blue` | `scholar-red` | `minimal-mono` |
|---|---|---|---|
| 白字 on `BAND`（大字 3.0 / 小字 4.5） | 5.41 | **8.48** | **13.39** |
| `SKY` on `BAND`（小字 4.5） | 4.77 | 7.19 | 11.44 |
| `BAND` on `TINT`（小字 4.5） | 4.99 | 7.65 | 12.17 |
| `BORDER` on 白底（小字 4.5） | 4.72 | 6.68 | 10.53 |
| 白字 on `BORDER`（大字 3.0） | 4.72 | 6.68 | 10.53 |
| 白字 on `NUM`（20pt 粗体 3.0） | 3.28 | 5.27 | 6.39 |
| `INK` on `TABBG`（小字 4.5） | 12.99 | 12.60 | 13.77 |
| `MUTED` on 白底（小字 4.5） | 6.10 | 6.40 | 6.90 |
| `ACC` on 白底（装饰线 3.0） | 3.00 | 3.72 | 4.95 |
| `BROWN` on 白底（**禁用承字** 3.0） | 2.67 | 4.74 | 3.36 |

**两套新主题各有一处比默认更宽裕、也更需要注意**：

- `scholar-red`：`BAND` 是暗红而不是正红，白字对比度 8.48:1，红底白字非常稳。
  但**红色在偏色投影上会往紫偏**，投影环境偏冷时优先选 `minimal-mono`。
- `minimal-mono`：`BAND` 是近黑灰，等于「无彩色」。代价是纯装饰色 `BROWN`
  只有 3.36:1（默认主题 2.67:1，都不能承字）；收益是 `ACC` 陶土橙 4.95:1，
  是三套里**唯一可以在白底上承小字的强调色**——但设计语言仍把它定位成
  标注/装饰色，分类靠位置不靠颜色。

### 怎么换主题

```powershell
python scripts\make_neutral_template.py --theme scholar-red   # 重新生成母版
python scripts\build_deck.py --theme scholar-red                # 出稿（另存 out/theme_scholar-red/）
```

或者在代码里：`kit.load_theme(name="minimal-mono")`（必须在建 deck 之前调用；
色板是模块级常量，页面函数 import 期就把值绑定了）。
主题定义在 `kit.BUILTIN_THEMES`，**母版生成脚本读的也是它**——
色板只写一份，不会出现「母版是蓝的、页面是红的」。

## 3. 字体

| 角色 | 默认 | 常量 | 说明 |
|---|---|---|---|
| 中文 | 微软雅黑 | `EAK` | 变体：`build_deck.py --zh-kaiti` 换成楷体 |
| 西文 | Times New Roman | `LAT` | 公式与大序号默认也是它 |
| 大序号 | Times New Roman | `NUMF` | 斜体，用于分层页的层号 |
| 公式 | Times New Roman Bold | `FORM` | 见下 |

**为什么西文统一 Times New Roman**：它在学术语境里正式、可信，
衬线体与中文黑体并置时层次清楚，也和绝大多数期刊/学位论文的西文观感一致。
早期版本试过 Comic Sans MS 与 Arial，前者在学术场合显得轻浮，
后者太平、与中文并置时缺少正式的对照感；两者都比 Times New Roman 宽 6%–17%，
会让按窄字体量出来的框在渲染时溢出。

**为什么公式不用等宽字体、而用 Times New Roman Bold**：早期版本用 Consolas，
靠等宽字身让 `=` 和 `+` 有「公式感」。但学术汇报里等宽字体的工程气质
与公式的数学气质是冲突的，容易读成代码。改用 Times New Roman Bold 之后，
等宽感可以用**加粗 + 轻微字距（`spc`）**补回来，代价小得多。
如果某页确实需要强等宽感（比如整页是算式），可以把 `FORM` 单独配成
Consolas / Cascadia Mono —— 但要注意闸门一的字宽模型会按字体名换表，
且 Consolas 每个字符固定 0.55em（比 Times New Roman 宽 7%–15%），
框要重新量。

### 两条必须记住的实现约束

1. **`run.font.name` 只写 `<a:latin>`。** 中文字形要另注入 `<a:ea typeface="微软雅黑"/>`，
   而且 `<a:ea>` 必须排在 `<a:latin>` **之后** —— 顺序反了 PowerPoint 读不到中文字体。
   `kit._style()` 已经处理了，页面代码不要绕开它自己设 `font.name`。
2. **中文字体不能走默认参数。** 写 `def txt(..., ea=EAK)` 会在 `def` 时把当时的
   `EAK` 绑定成默认值，之后外部改 `kit.EAK` 一个字也改不到——字体名照写进 XML，
   就是不换。所以 `kit.txt()` 的 `latin` / `ea` 默认是 `None`，在函数体里现取。

### 字号阶梯

| 用途 | 字号 |
|---|---|
| 封面主标题 / 结尾大字 | 30–54pt Bold |
| 正文页主标题（标题带内） | 28–30pt Bold |
| 卡片标题 / 表内强调 | 15.5–17pt Bold |
| 正文 | 13–15pt |
| 章节标签 / 图注 / 页脚 | 10.5–12.5pt |

行距：正文 `ls=1.30–1.36`，单行说明 `ls=1.24–1.28`，大标题 `ls=1.20–1.30`。
闸门一按 `行距 = 字号 × ls × 1.22` 算高度，ls 给大了会直接算成溢出。

## 4. 版式装饰（**永远不要在页面里重画**）

装饰是**版式里的非占位符普通形状**。`add_slide(版式)` 只克隆占位符，
装饰由 LibreOffice / PowerPoint 自动画在幻灯片下层。所以：

- 页面函数**一行装饰都不要加**——任何自绘色块盖上去都会盖住版式自带的东西；
- 需要一块深色结论带时用 `rect(fill=BAND)`，那是**内容**不是装饰，放内容区；
- 封面尤其要克制：内置母版的封面左下压着几何块，文字列从 x≈6.95 起排。

内置中性母版（`assets/theme-neutral.pptx`）的装饰：

| 版式 | 装饰 |
|---|---|
| `标题幻灯片`（封面） | 左下 `SKY` 大面 + `ACC` 顶边线 + `TABBG` 圆 + `BROWN` 半透明圆 + `BAND` 竖分隔 |
| `标题和内容` / `两栏内容` | `BAND` 满宽标题带（y 0.41–1.24）+ `ACC` 带下线 + 右上 `BROWN` 块 + 两枚白色菱形 |
| `末尾幻灯片` | 整块 `SKY` 底（y 1.86–6.50）+ 顶部 `BROWN` 细色线 + 底部 `BAND`/`ACC` 两条细线 |

**零机构标识**：无校名、无校徽、无机构照片。所有装饰都是抽象几何。
换自有版权的模板时，那份版权由用户自己承担（见 `template-intake.md`）。
