# 设计技巧：风格、边界与布局

> 这份讲**为什么这么排**。所有数值（栅格、字号、间距、对比度阈值）都在
> `design-language.md`，异常排查在 `pitfalls.md`。两份文档不重复：那边是规格书，
> 这边是判断标准。

读完这份应该能回答一个问题：**这一页这样排，是刻意的还是随手放的？**
闸门能抓到溢出、越界、对比度、空隙，抓不到「这样排不好但也没违反任何规则」。

---

## 1. 风格：先定基调，再谈配色

配色是风格里最晚决定的那一项，通常也是最先被决定的那一项。先问三个问题：

| 问 | 答案决定 |
|---|---|
| 谁在看？ | 导师一人的组会 ≠ 五位评委的答辩 ≠ 校外评审 |
| 什么投影环境？ | 教室偏色投影会把红底推成紫、亮蓝推成白 |
| 看完要记住什么？ | 决定每页留几句话的预算 |

### 1.1 正式度是有梯度的

从松到紧，四档，别跳档：

1. **工作记录**：组会内部、进度汇报 → `minimal-mono`，灰阶，打印友好
2. **正式汇报**：组会对外、中期 → `academic-blue`
3. **评审场合**：开题、答辩、结题 → `scholar-red`，结论感更强
4. **演示场合**：路演、大会、大屏 → `midnight`（暗底）

跳档的典型失误：内部组会套了答辩的红色主题，导师会问「这次是不是要结题了」。

### 1.2 一份稿一个隐喻，不混用

一份汇报从头到尾只用一套视觉隐喻。选了「流水线五工位」就到底，不要在后面
突然换成「地图路线」或「金字塔」。混用隐喻会让听众每翻一页都重新建立心智模型，
这个成本比看起来大得多。

隐喻一旦选定，标题、页型、讲稿三处的说法要一致。屏上叫「工位」，讲稿里就别叫
「环节」，哪怕想换词避免重复——先换隐喻，别在一套隐喻里乱换词。

### 1.3 克制：结论页与数据页不加装饰

装饰性元素（色块、图标、分隔线的花样）在**论述页**有用，在**结论页和数据页**是噪声。
听众在结论页要的是那句话，不是背景图案。判断标准：把这一页的装饰全删掉，
信息量有没有损失？没有损失就不该有。

## 2. 标题写法

标题是这份稿里唯一被每个人、每一遍都读到的东西，也是最容易写得像 AI 的地方。

### 2.1 说发现，不说主题

| 不要写 | 要写 |
|---|---|
| 检索路径对比 | 关键词只有 0.398，图谱扩展补上 27.8 个百分点 |
| 两个实验的结果 | 两个方面胜出，一条边界 |
| 云端与本地对比 | 抽取：云端全胜，还更快 |
| 实验二 | 微调上生产线，云端只接抽取 |
| 相关工作 | 榜单把模型与脚手架分开打分 |
| 结论 | 词面接不上的那一跳，图谱补上了 |

左边那种标题，听众看完只知道「这页讲什么」，不知道「这页说了什么」。
组会汇报不是论文提纲，每一页的标题都应该能独立当一句话结论被引用。

**例外**：封面、目录、章节分隔页写主题名是对的，那几页本来就不承载结论。

### 2.2 反 AI 味的七类词

这些词单看没毛病，堆在一起就是 AI 稿的味道。**交付前全文搜一遍**：

| 类别 | 典型词 | 问题 |
|---|---|---|
| 姿态词 | 如实、照实、不美化、不藏、诚实 | 自我表功，听众只需要数字 |
| 结论预告 | 先说结论、结论怎么下、结论如下 | 结论就在下面，不必先宣布 |
| 三段式 | 首先…其次…最后、第一…第二…第三 | 中文书面语的自然断句不需要这个脚手架 |
| 空转动词 | 赋能、打通、闭环、沉淀、抓手 | 没有任何可验证内容 |
| 虚化判断 | 具有重要意义、值得关注、体现了 | 说了等于没说 |
| 过度让步 | 虽然…但是…不过总体来看 | 让步本身就是在稀释结论 |
| 同义反复 | 全面胜出，而且更快（全面已含更快） | 用词冗余 |

改法不是换同义词，是**把姿态删掉，只留事实**：

- 「云端在这里全面胜出，而且更快——如实报告」→「抽取：云端全胜，还更快」
- 「两个方面胜出，一条边界照实交代」→「两个方面胜出，一条边界」
- 「云端逐工位对比」→「云端只接抽取」（"逐工位对比"是过程，"只接抽取"是结论）

### 2.3 重复是 AI 稿最明显的破绽

一句话在一份稿里出现 3 次以上，听众第二次就意识到你在凑字数。
实测一条经验：把最得意的口号句全文搜一遍，超过 2 次就删到只剩结论页那一处。
口号的作用是收束，出现两次已经超配。

同义词轮换也一样：同一件事换了五个说法，听众以为发生了五件事。

### 2.4 字数、断句与标点

- **标题 ≤ 18 字**，逗号断句不超过两处。超过就拆成两行或砍掉修饰。
- 中文之间用全角标点；**中文与数字、英文之间加一个半角空格**（`6 GB 显存`、
  `40 亿参数`、`Recall@10 为 0.861`），不加空格会挤成一团。
- 不要用「——」硬接第二句。破折号后面的内容通常是废话。
- 不用英文句号和英文逗号混在中文句子里。

## 3. 视觉层级

一页里只有三档信息，多了就是没有层级：

| 档 | 作用 | 视觉手段 |
|---|---|---|
| 主 | 这一页的一句话结论 | 标题带，最大字号 |
| 次 | 支撑结论的证据 | 数字、图、表格 |
| 辅 | 口径、来源、免责声明 | 最小字号、最弱颜色 |

三条纪律：

1. **不许全员加粗。** 全员加粗等于没有加粗。粗体是稀缺资源，一页里粗体总数
   控制在 5 处以内。
2. **不要用颜色表达层级。** 层级靠字号和位置，颜色靠语义（结论、警示、弱化）。
   一个颜色只承担一个含义，全程不换。
3. **辅助信息不许抢主信息的位置。** 口径说明、来源标注永远在页面下沿或右栏，
   不能和主内容同大、同色。

## 4. 布局与阅读顺序

### 4.1 视线动线要顺着说

中文幻灯片的自然阅读顺序是左上 → 右上 → 左下（F 形）。内容必须顺着这个顺序
讲：标题在上，主张在标题正下方，证据在主张下面，收口在最下沿。

最常见的错误是**左右分栏时，左栏讲结论、右栏讲前提**——听众读完左栏就以为讲完了。
如果确实需要并列，两栏必须是同类型的东西（两个方案、两个配置），不能是
「结论 + 解释」。

### 4.2 对齐是纪律，不是审美

一份稿只用一套基准线。左边距统一，所有文字块左缘对齐；标题带和正文块的左缘
对齐；右栏的右缘对齐。**不要在同一页里混用左对齐和居中对齐**——居中对齐只用于
封面、结尾、金句页这三类无阅读方向的页面。

对齐错了，闸门抓不到（文字没溢出、没越界），但听众会一直觉得别扭。
排完一页，退一步看左缘是不是成一条直线。

### 4.3 留白是节奏，不是剩余

留白的意义是**告诉听众哪里是断句**。两个块之间的缝，就是听众停一下的地方。

- 块间距要落在规格里（见 `design-language.md`），但更重要的是**相邻块间距要一致**。
- **密度要有节奏**：密页（数字墙、对照表）后面接疏页（结论页、金句页），
  不许连续两页同样密。连续两页满页表格，第三页听众会直接跳过。
- 页底不要留尾巴。内容压到页脚线附近，要么上移，要么删一块。
  一条经验：留白预算别用满。`qa_layout` 的空隙阈值是硬线，但**换字体、换文案
  之后字距会漂移**，贴着阈值排的版面下次改一句话就塌。留 20% 余量。

### 4.4 不要平均三等分

三个人最容易犯的布局错误是把三件事平均切成三栏。平均分意味着没有任何优先级，
听众不知道该看哪个。要么明确标出主项（更大、更靠左、有色带），要么改成
「一大两小」的非对称布局。

对称是庄重，不对称是判断。组会汇报需要判断。

### 4.5 每行字数有上限

- 正文一行 **28–36 个中文字**，超过就要换栏或缩到下一档字号。
- 页脚与图注一行 **不超过 40 字**，超过说明该说进正文了。
- 一行只有一个标点断句机会；两个以上就是句子太长了。

## 5. 边界：三类边界

### 5.1 空间边界

页面有硬边界，超出就是缺陷。闸门会抓，但闸门抓的是「有没有出」，不是「离得远不远」：

- 外边距、页脚安全带、组件框 —— 数值见 `design-language.md` §1。
- **组件边界比页面边界更容易被忽视。** 文字没出页面但出了卡片框，闸门三会抓，
  但只在对比度检查里附带发现，不看这一项就漏了。
- 图注和图之间留缝，别让图注贴着图的下边缘。

### 5.2 内容边界：什么放屏上

这是最容易判断错的一类边界。**屏上放结论，讲稿放过程，备注放辩护。**

| 内容 | 去处 |
|---|---|
| 一句话结论、关键数字、对比表 | 屏上 |
| 推导过程、为什么这么比、口径选择 | 讲稿（口述） |
| 假设区间、样本量、未终审、重复性 | 屏上标注 + 讲稿展开 |
| 预设问答、可能被追问的点 | 讲稿末尾 |
| 调试信息、路径、内部编号 | 不出现 |

屏上写不下的，不要缩字号硬塞。**缩到 10pt 以下的内容等于没写**——它在投影上
不可读，听众只会看见「这里有一堆字」，比空白更糟。删掉或搬到讲稿。

### 5.3 数据边界：口径纪律

这是科研汇报里唯一会被追问、且追问了就下不来台的边界：

1. **自评数据要交代状态**：未终审、未重复、单次执行、假设区间，哪个适用就标哪个。
2. **样本量小说样本量小。** 不要为了显得严谨把小样本算成显著，也不要为了显得
   谦虚把大样本说成初步。按相对值说话。
3. **口径必须对称。** 比较两边时，如果披露了一边的测量口径（比如「云端是端到端
   墙钟时间」），**就必须披露另一边的口径**（比如「本地 2.5 ms 只是矩阵乘中位数，
   不含查询向量化」）。只披露一边，比较就被放大了，听众不会自己发现，但他们会
   记住这个数字，回来追问。
4. **倍数要算准，且从精确值算。** 屏上显示的是取整值，倍数必须用原始精确值除，
   不能拿屏上那个四舍五入的数反算。`65.0 s ÷ 2.4529 ms = 2.6 万`，写成 2.7 万
   就是错，而且这种错一眼就能看出来。
5. **百分点 vs 百分比 vs 倍，不要混用。** 0.861 对 0.676 的差是 18.5 个百分点，
   不是 18.5%；0.741 对 0.398 的比是 1.9 倍。三者不能互换。

### 5.4 署名与版权

模板里的校名、校徽、机构照片属于模板作者，**用之前问用户有没有权限**。
引用论文原图必须标注来源与出处（作者、会议、年份、图号），并在交付说明里
声明「仅作学习汇报使用，观点归属原作者」。这一条不问用户就自己决定，是越界。

## 6. 中西文混排

实现约束（`<a:ea>` 顺序、默认参数绑定）在 `design-language.md` §3，这里说排版原则：

- **中英文之间加半角空格**：`Qwen3.5-0.8B 模型`、`用 vLLM 部署`。不加是中文排版
  里最明显的业余痕迹。
- **数字与单位之间加半角空格**：`6 GB`、`22.6 W`、`77 ℃`、`2.5 ms`。
  摄氏度的 ℃ 是符号，前面加空格。
- **中文与英文数字之间也加空格**：`18,204 条`、`10 条需求`。
- **公式里不加空格**：`Recall@10`、`0.861 vs 0.676` 保持紧凑。
- 千分位用半角逗号：`18,204` 不是 `18，204`。
- 小数统一两位或统一一位，一份稿里不要混。
- 中西文字号**按视觉高度对齐**，不按磅值。西文字号通常要比中文字号大半到一档，
  否则视觉上西文明显偏小。

## 7. 数字与图表的诚实呈现

- **坐标轴不从零开始要标出来。** 截断的 Y 轴会把 10% 的差别画成 100% 的柱子差。
  要么从零开始，要么在图注里写明「Y 轴自 0.6 起」。
- **量级差不要硬画在同一个坐标轴上。** 2.5 ms 和 65.0 s 画在一根轴上，小的那个
  看不见。用对数轴、双轴、或者干脆只写数字不画图——三种解法见
  `figures-and-charts.md`。
- **误差棒不是装饰。** 有重复实验就画，没有就别画假装有的。
- **未参评的项要标出来，不能默默消失。** 缺席的数据在图上是空白，听众会以为
  没做。
- **图能编辑就别用图片。** 柱状、条形、单系列折线走原生图表，听众想改一个数
  能直接双击进 Excel。规则见 `figures-and-charts.md` 的分工表。

## 8. 交付前自检清单

按顺序过，前三条不满足就不必看后面：

- [ ] 每一页标题单独读一遍，是不是每页都说出了一个结论？
- [ ] 全文搜一遍 §2.2 那七类词，命中数是否为 0？
- [ ] 全文搜最得意的口号句，出现次数是否 ≤ 2？
- [ ] 数字逐项核对：屏上、图注、讲稿三处是否一致？倍数是不是从精确值算的？
- [ ] 比较类内容：两边口径都披露了吗？
- [ ] 字号最小的一档在投影上还能看见吗？看不见就删掉内容
- [ ] 左缘对齐成一条直线了吗？
- [ ] 有没有连续两页同样密？
- [ ] 每页留白余量是否留了 20%，有没有贴着阈值排的？
- [ ] 图注序号连续、来源集中、等比未拉伸？
- [ ] 四道闸门全绿，且阈值没有被放宽过？
- [ ] 交付说明里写清了口径与限制，没有替你拍板该不该进论文？
