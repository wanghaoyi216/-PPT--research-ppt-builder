# 用户自带模板接入流程

`assets/theme-neutral.pptx` 是内置的零版权母版。但多数课题组手里已经有一份
「组会一直用的那份模板」——换掉它没有意义，认它才有意义。
这一页讲怎么把任意 `.pptx` / `.potx` 接进来。

---

## 核心思路：不重画，直接当母版用

```
以用户模板为基座打开  →  add_slide(版式)  →  删掉克隆来的占位符
                                    ↓
                     版式里的非占位符装饰自动画在下层
```

所以「仿模板」不是照着截图描一遍，而是**把模板本身当母版**：
母版和版式原封不动地留在包里，页面代码一行装饰都不用加。
换模板之后要改的只有**色板、字体、栅格**这三样——也就是一个 `theme.json`。

---

## 四步

### 1. 反推视觉语言

```powershell
python scripts\analyze_template.py "D:\组内某某\我的模板.pptx"
```

输出四块：主题色 / 字体族、母版与版式清单（含**每个版式里非占位符装饰形状的真实
几何与填充色**）、栅格推断（边距 M、内容区宽 CW、标题带上下沿与颜色、页脚带起点）、
以及版式名能不能对上 kit 的四个角色。

同时写一份 theme.json：

```powershell
python scripts\analyze_template.py "D:\…\我的模板.pptx" -o theme.json --strict
```

`--strict` 表示「版式角色没靠**版式名**命中就非零退出」，接流水线时用。
名字一个都没对上、只靠几何兜底猜出来的角色也会被它拒掉——猜对不等于对，
那种模板（版式全叫 `Layout_N` 的 4:3 尤其容易碰巧猜对版式序）请手工指定 `layouts`。

### 2. 补色板的语义映射

`analyze_template.py` **故意不自动填 `palette`**。它只能告诉你「有哪些颜色、
用在哪」，判断不了「这个深蓝是标题带还是结论带」——那是看图说话的事。
照着 `references/design-language.md` 的语义表把颜色对上：

```jsonc
"palette": {
  "BAND":   "1F4E79",   // 模板的标题带色 → 承担标题带 / 结论带 / 深色面板
  "BORDER": "4472C4",   // 内容框描边色
  "ACC":    "5B9BD5",   // 装饰线色（务必确认它承不住字）
  "SKY":    "DEEAF6",   // BAND 上的浅色字
  "TABBG":  "D9E2F3",   // 编号标签底
  "NUM":    "8FAADC",   // 编号圆
  "TINT":   "F2F6FB",   // 淡底卡片
  "BROWN":  "B39B77",   // 模板点缀色，纯装饰
  "INK":    "0F1423", "BODY": "262626", "MUTED": "56646E", "WHITE": "FFFFFF"
}
```

**填完必须逐个核对比值**，规则见 `design-language.md` 第 2 节。
沿用别人的色板最容易出的事故就是拿不准对比度：那个深蓝在白底上够不够 4.5:1？
压在它上面的浅色字够不够 4.5:1？闸门三会报，但那时页都写完了。

### 3. 核栅格

`grid` 段直接用反推值，但有两处要人眼确认：

- **`CT_TOP`**（内容区顶）= 标题带下沿 + 0.42。反推值是按这个经验公式算的，
  要看标题带下方还有没有章节标签行——有的话 `CT_TOP` 要再往下挪 0.3 左右。
- **`FOOT_TOP`**（页脚带起点）反推值是 `页高 − 0.52`。模板页脚带更高就往下调。

栅格对不上的后果是闸门一误报「压页脚」、闸门四误报「提前收工」——
先改栅格，再怀疑页面。

### 4. 跑一遍验证

```powershell
python scripts\verify_all.py --pptx out\我的汇报.pptx --manifest out\我的汇报_layout.json
```

## 模板名对不上怎么办

`analyze_template.py` 的 `resolve_layouts()` 走两级匹配：

1. **别名表**：`cover` → `标题幻灯片 / 封面 / Title Slide / 首页`，`content` →
   `标题和内容 / 正文 / Title and Content`，`close` → `末尾幻灯片 / 结尾 / Thank you`…（大小写不敏感）
2. **几何兜底**：还没定下来的角色，按「有没有标题占位符」+「非占位符装饰形状个数」
   排序取最像的那个，并在输出里标 `几何兜底（非名称命中）` —— 让你知道它不是猜准的。
   `--strict` 见到这个标记就非零退出：它靠的是弱特征，猜对也只是巧合。

两级都判不出来，会**明确报错**并列出该模板的全部版式名：

```
[需要人工确认] 未能判定角色：cover
    模板全部版式名：['Slide 1', 'Slide 2', '自定义版式', ...]
    处理：把对应版式在 PowerPoint 里改名成 '标题幻灯片' 之类，
          或直接手改 theme.json 的 layouts 字段。
```

**不做静默降级。** 版式配错的后果不是「少个装饰」，而是版式自带的装饰整片丢失，
页面看起来像没设计过——这种错误必须在第一步就炸出来。

配好之后：

```jsonc
"layouts": { "cover": "首页", "content": "正文页", "two_col": "双栏", "close": "尾页" }
```

## 模板带机构标识怎么办

用户自己的模板里通常有校名、校徽、校园照片。**这是用户自己的版权，不阻塞流程**，
但要**明确说一次**，让用户自己确认能不能公开场合放映。

- 只在本组内用 → 没问题；
- 要投会议 / 答辩 / 公开分享 → 提醒用户确认标识使用范围；
- **不要把带标识的模板打进 skill 包再分发**。内置母版之所以是抽象几何，
  就是为了这条红线。

同样的道理适用于**图片素材**：论文原图、他人数据集截图在汇报里用是常见做法，
但图注要注明出处，且不要打包进 skill 包。

## 常见情况速查

| 情况 | 现象 | 处理 |
|---|---|---|
| 模板里没有封面版式 | `KeyError: 模板里没有版式「标题幻灯片」` | 换一个可用版式当封面，或用内置母版 |
| 模板没有标题带（纯文本模板） | 栅格报告里「标题带：未找到满宽色带」 | 标题带改由页面自己画：`rect(fill=BAND)` + 白字，`CT_TOP` 手动定 |
| 模板是 `.potx` | 与 `.pptx` 同一条路径，直接喂进来 | 不用在 PowerPoint 里另存（实测 python-pptx 可正常打开） |
| 模板是 4:3 | 页面尺寸与 `W/H` 不符 | 换 16:9 模板，或改 `grid.W/H` 并重排全部坐标 |
| 装饰是图片而不是矢量 | 闸门三要靠像素兜底才判得出底色 | 内置母版已经处理；用户模板下正常也能兜住 |
| 模板自带示例页 | 产物里多出十几页空白 | `kit.open_base()` 已经会清空；若仍有残留说明不是标准 pptx 结构 |
